# Product Store

This project is a product management interface that fetches data from an external API and displays it in a structured table.  
The goal of this project is to understand global state management and handling complex UI interactions.

## Concepts Learned

- Fetching data from an external (dummy) API  
- Storing and managing data using a global state  
- Displaying data in a tabular format using a data grid  
- Editing row data directly within the table  
- Deleting selected rows from the dataset  
- Exporting table data into a CSV file  
- Opening a modal to view detailed product information  

## What This Project Showcases

This project showcases how to manage and manipulate large datasets in a React application.  
It demonstrates handling user actions like edit, delete, and export, along with dynamic UI updates and structured data presentation.
